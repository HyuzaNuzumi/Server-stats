## 📌 About The Project

**Server Performance Stats** adalah script shell berbasis Bash yang dirancang untuk membantu sistem administrator dan pemula Linux menganalisis metrik performa server secara cepat dan efisien.

Script ini mengambil data kesehatan sistem secara langsung menggunakan utilitas CLI bawaan Linux tanpa memerlukan dependensi eksternal.

### Key Metrics Tracked:
- **CPU Usage:** Persentase total konsumsi CPU.
- **Memory Usage:** Penggunaan RAM (Terpakai vs Bebas beserta persentasenya).
- **Disk Usage:** Penggunaan ruang penyimpanan disk sistem.
- **Top Processes:** 5 proses teratas yang mengonsumsi CPU & Memory tertinggi.
- **System Info:** Versi OS, uptime server, dan load average.
